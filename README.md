##  Overview

**AI-PhishDetect 2026** is a zero-shot phishing detection system that uses Large Language Models to identify AI-generated phishing emails. Unlike traditional keyword-based scanners, it understands **semantic intent, urgency manipulation, and deception patterns** in email content.

Built in **Beirut, Lebanon** for the global 2026 threat landscape.
